# Phase TH-0: Thailand source investigation (read-only, no code)

**Date:** 19 October 2026 · **Plan:** `Thailand parity + cascading dashboard country filter` (TH-0..TH-8)

**Status:** done — no scraper code written. Each of the 8 `sources` rows for region `TH` was visited live (Chrome, with a WebFetch cross-check where the browser extension was blocked) and classified for TH-3.

## Findings per source

| `sources.code` | Base URL | Classification | Evidence |
|---|---|---|---|
| `TH_GAZETTE` | `https://ratchakitcha.soc.go.th/` | **(b) scrapable, Playwright** | Loads cleanly, **no captcha/login**. Home page lists the 2 most recent gazette notices; a "ราชกิจจานุเบกษาล่าสุด ๑๐๐ รายการ" (latest 100) link reveals a `#list-tab` listing — each entry has category, title, date, and a `เล่ม <volume> ตอนที่ <issue> หน้า <page>` citation (the exact Royal Gazette volume/issue/page shape `docs/CLASSIFICATION_DESIGN.md` expects), plus a "ดูรายละเอียด" (view details) button per row leading to the notice/PDF. Content renders client-side (hash-routed `#list-tab`), so Playwright is the right tool, not plain HTTP. **Correction to the plan's R1 assumption**: this site is markedly more open than India's e-Gazette (no `CaptchaRequired`-equivalent gate was hit in this session). |
| `TH_TISI_MANDATORY` | `https://www.tisi.go.th/website/standardlist/comp_thai/th` | **(a) scrapable, static HTML, but with a data gap** | Server-rendered list of all 152 mandatory มอก. standards, grouped by product category (เคมี, ปิโตรเลียม, พลาสติก, ...), each row showing the มอก. number, Thai title, and effective date (`วันที่มีผลบังคับ`). No captcha; one cookie-consent banner only. **However**, every "รายละเอียด" (details) link tested (2/2) pointed to `www3.tisi.go.th/hscode/hscode_view.asp?id=<n>`, which returned an **IIS 404 — broken on the live site**. This page is good for the canonical registry (which มอก. numbers are mandatory + effective dates) but not for document text/PDFs; pair it with `TH_TISI_DB`/`TH_TISI_PORTAL` for that. |
| `TH_TISI_DB` | `https://appdb.tisi.go.th/tis_dev/p3_tis/p3tis.php` | **(a) scrapable — real backend API found** | A filterable DataTable UI ("แสดงรายการ มอก. บังคับ" = show mandatory list). Network inspection found the data comes from a **POST JSON/form endpoint `https://appdb.tisi.go.th/tis_dev/p3_tis/get_tis_data.php`** — this is a genuine semi-API, scrapable with `sources/http.py` (no Playwright needed) once the POST parameters are reverse-engineered. Each row's "รายละเอียด" button links out to `TH_TISI_PORTAL`. |

## Summary for TH-3 prioritization

- **Prioritize first**: `TH_GAZETTE` (open, structured, Playwright) and the `TH_TISI_DB` + `TH_TISI_PORTAL` pair (open, structured, `TH_TISI_DB` has a real POST API and `TH_TISI_PORTAL` has the richest per-standard record — these two together cover both the `GAZETTE_NOTICE` and `TIS_STANDARD` doc classes end to end).
- **Usable but partial**: `TH_TISI_MANDATORY` — good for the canonical "what's mandatory + since when" registry, but its own detail links are broken on the live site; don't rely on them, cross-reference มอก. numbers against `TH_TISI_DB`/`TH_TISI_PORTAL` instead.
- **Needs retry before scoping a crawler**: `TH_DLT`, `TH_PCD`, `TH_TISI_NEWS` (all unreachable this session — re-check from a different network before concluding they're captcha/login-gated or genuinely down), and `TH_INDUSTRY`'s `law.industry.go.th` subdomain specifically (the main `industry.go.th` site itself is fine).
- **No captcha or login gate was encountered anywhere in this session** — every failure was a connectivity/availability problem (error page, connection refused, broken link), not an anti-bot gate. This is a materially better starting position than the plan's R1 risk note assumed, especially for `TH_GAZETTE`, which was expected to be captcha-gated like India's e-Gazette and was not.
