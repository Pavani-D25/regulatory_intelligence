RegTrack India · Work log

What we built on 7–8 October 2026, what went wrong, and how we fixed it

In one working day RegTrack India went from an empty folder to a working system. It collects Indian vehicle regulations from four government sources, reads and organises them, and shows them in a portal built to the approved design. Everything shown comes from real downloaded documents.

Project: D:\regulatory_intelligenceRepository: Pavani-D25/regulatory_intelligence (private)Scope: India · vehicle categories L1, L2, M1, N1

We worked in three blocks: a night block building the data pipeline, an afternoon block adding a first dashboard and quality fixes, and an evening block rebuilding the dashboard in the approved portal design and cleaning the data. What RegTrack is

RegTrack watches the official sources for Indian vehicle regulations and keeps an organised, searchable record of them.

MoRTH · ARAI · e-Gazette · India Code→Download every 6 hours→Read and identify each document→PostgreSQL database→Portal at localhost:5173
  • Sources: MoRTH (notifications, orders, guidelines), ARAI (AIS standards), e-Gazette of India, India Code (Motor Vehicles Act and Central Motor Vehicles Rules).
  • Original files are stored once and never changed, named by their SHA-256 fingerprint.
  • Identity comes from the document's own text, never from the website's title. For example GSR-659(E)-2022 or AIS-038(Rev.2).
  • Scope: two-wheelers (L1, L2), cars (M1) and light goods vehicles (N1). Everything else is stored but marked out of scope.

3 · The approved portal design evening

We were given an approved HTML design: a static mock-up with made-up numbers. We rebuilt it with the same look and all of its views, connected to our real data, for India and our four vehicle categories only.

The nine views: Dashboard, Regulations, Change Monitor, Compliance Matrix, Impact View, Ask Regulatory AI, Reports, Alerts and Admin, plus a detail drawer for any regulation. Team inputs (reviews, compliance owners and evidence, alert rules, settings, report history) are stored in new database tables. The earlier vehicle check and version pages stay available under "Tools".

4 · Making it fully live evening

A check for anything static found a few problems:

  • "Scheduled Reports: 0" was a fixed number. Replaced with the time of the last real report.
  • Two Admin switches did nothing. "Automatic source sync" now really pauses and resumes downloads; the other was removed.
  • Category names, topic names, sync sources, AI suggested questions and workflow steps were typed into the code. They now come from the database.
  • The 6-hour auto-download was not running. We started it, added a heartbeat every 5 minutes, and the sidebar now shows "Auto-sync running / not running / paused".
  • Added a "Sync All Sources" button that downloads from all four sites one after another; a failing site does not stop the others.

5 · Refinements evening

  • Detail drawer now shows obligations with dates, related documents (both directions) and version history.
  • Live refresh: pages reload by themselves when a sync brings new data. A notification bell shows new alerts.
  • Regulations list: full width, sortable columns, 50 per page, superseded documents hidden unless asked.
  • Change Monitor: filters by change type, a review button per change, and both dates shown (when we found it, and the document's own date).
  • Counts made consistent: every change count now covers only our four categories.

6 · Data clean-up evening

Motor Vehicles laws

The Motor Vehicles Act 1988 was tagged only for L2, because the system had picked up words mentioned inside the text. The Act, its amendments and the Central Motor Vehicles Rules 1989 now apply to all vehicles. Twelve old Acts that amended the repealed 1914 and 1939 Motor Vehicles Acts are marked superseded. All 34 Acts were checked one by one.

Drafts stored as published standards

Sixteen draft AIS standards, including AIS-221 to AIS-230 and the new Bharat NCAP revision AIS-197(Rev.1), were stored as final standards in force. Six standards actually in force (AIS-021, AIS-029, AIS-031, AIS-126, AIS-197, AIS-216) had been marked as replaced by them. All are now correct, and every standard family still has exactly one current version.

Document titles

Junk titles in the library went from 81 to 23, and no title got worse. Sources now used, in order of trust:

  • Draft cover lines, e.g. "Draft Corrigendum No. 1 to AIS-185: Approval of vehicles with regard to the Advanced Emergency Braking System".
  • ARAI's own title for the exact standard, matched by number, part and draft/published.
  • The name a notification gives itself ("These rules may be called the Motor Vehicles (Driving) Regulations, 2017").
  • A website listing title, but only when it names the same notification number as the document. Six MoRTH listings name the wrong notification.

Reference documents

35 documents that are not regulations (19 reports, 11 AIS-007 form tables, 5 unclassified items such as ARAI's index page) are hidden from the register by default, with a "Show reference documents" switch. Nothing was deleted.

7 · Easy start for teammates evening

A new collaborator needs only Python 3.11+, Docker Desktop and Node.js 18+. One command does the rest.

.\start.ps1 -Snapshot file.dump./start.sh --snapshot file.dumpLoad a teammate's database snapshot first

  • Database snapshots: snapshot-export makes a 22 MB file in 5 seconds. A test restore into a separate database gave identical counts (2,064 documents, 148,323 clauses, 178 obligations).
  • Works in any folder: stored files are found by their SHA-256 name even when the snapshot came from another machine.
  • No browser download on Windows: the crawlers use Chrome, then Edge, then Playwright's own browser.
  • Tested here: both scripts set up, start, and stop the services cleanly. Running them again is safe.

How to run it

In PowerShell, from D:\regulatory_intelligence, with Docker Desktop running:

start.bat                                         # Windows: set up if needed, start everything
./start.sh                                        # macOS / Linux / Git Bash
.\start.ps1 -Stop                                 # stop again

When the AI address arrives: add LLM_BASE_URL and EMBED_MODEL to .env, then run python -m regtrack.cli llm-smoke to test, and python -m regtrack.cli run to process everything.
